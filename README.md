# Customer Segmentation using RFM Analysis

## Project Overview

This project analyzes customer purchasing behavior using **RFM (Recency, Frequency, Monetary) analysis**.

The goal is to segment customers based on their purchasing behavior and identify meaningful customer groups that can help the business make better customer-retention and marketing decisions.
